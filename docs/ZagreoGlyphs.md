# Zagreo Glyphs 1.1.2

Zagreo Glyphs generates vector-path animation moments from ASS text or drawings.

Menu root: `Zagreo Glyphs`

Namespace: `kite.ZagreoGlyphs`

## Main areas

- Font, pair, blob, and contour morphs.
- Surface, wave, radial, edge, ink, drip, path, reveal, dissolve, fold, impact, shatter, glitch, and sketch effects.
- Static drawings or text converted through Yutils.
- Optional baked AE position tracking.
- Controlled confirmations and simplification for large output or complex shapes.

The main chooser is registered as `Zagreo Glyphs`, help as `Zagreo Glyphs/Help`, and direct effect actions under `: Kite Hotkeys :/Zagreo Glyphs/...`.

Settings persist through the shared Kite UI settings store.
