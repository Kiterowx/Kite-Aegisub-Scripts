# Kite Aegisub Scripts

A collection of Aegisub automation scripts for timing, quality control, typesetting, motion tracking, vector animation, clip work, gradients, image conversion, snapshots, transform effects, and color management.

## DependencyControl

DependencyControl update information is provided in `DependencyControl.json`. The feed includes the public macros listed above and the shared `kite.EventOps`, `kite.LineOps`, `kite.Media`, `kite.PyBridge`, `kite.ShapeOptimizer`, `kite.Timing`, and `kite.UI` modules. Stable preferences are stored by namespace in `?user/config/kite.settings.json`.

Feed URL:

```text
https://raw.githubusercontent.com/Kiterowx/Kite-Aegisub-Scripts/main/DependencyControl.json
```
